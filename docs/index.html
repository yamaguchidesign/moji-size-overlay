プライバシーポリシー（文字サイズオーバーレイ）

最終更新日: 2026年4月29日

本プライバシーポリシーは、Chrome 拡張機能「文字サイズオーバーレイ」（以下「本拡張機能」）における情報の取り扱いについて説明するものです。

1. 収集する情報

本拡張機能は、ユーザーの閲覧ページの内容や閲覧履歴を収集・記録・外部送信することはありません。

2. 端末内に保存する情報

本拡張機能は、利用設定（サイトごとの表示のオン／オフ、表示モード）を、ブラウザが提供する chrome.storage のローカル領域に保存します。当該情報はユーザーの端末内に留まり、開発者のサーバーへ送信されることはありません。

3. 権限の利用目的

  • activeTab: ユーザーが操作中のタブに対して、ポップアップからの指示に応じてオーバーレイ表示の状態を反映するために使用します。
  • storage: 前項の設定を保存し、次回以降の利用時に同じ設定を復元するために使用します。
  • ユーザーが任意の Web ページで本機能を利用できるよう、コンテンツスクリプトを各ページに読み込みます。これは画面へのオーバーレイ表示のためであり、ページ内容を収集する目的ではありません。

4. 第三者提供

本拡張機能を通じて取得・保存する情報の第三者への販売・提供は行いません。

5. リモートコード

本拡張機能は、拡張機能パッケージに同梱されたローカルの JavaScript / CSS のみを実行します。外部サーバーからスクリプトを読み込んで実行する処理はありません。

6. ポリシーの変更

本ポリシーの内容を変更する場合、本ページを更新します。
